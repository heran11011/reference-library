## 使用边界

- magpie 这里只作为 API 路由和配额管理工具收纳，不会赠送会员，也不会增加服务商订阅额度；需要自己已有且获授权使用的账号、API 或本地模型。
- 本次仅核实公开元数据与 README，未安装、未实测，也未完成源码安全审查；不代表已连接任何本机账号。
- 按 README，它会读取已登录 Agent 的账号信息并调整模型配置，隐私遮蔽默认关闭；使用前需确认账号发现、配置修改和数据去向，不把工具宣称当作安全保证。
- 不公开账号、凭证、请求内容或配置备份；共享网关与第三方订阅使用还需核对服务条款和访问权限。

项目以 Git 子模块固定到 fork 默认分支的实际提交，来源与版本见 [sources.json](../sources.json)。
